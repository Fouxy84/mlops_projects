# Optional Evolutions

Ce dossier contient deux pistes d'evolution qui ne modifient pas la stack active.

- `option_1_streamlit_interface/`
  Ajoute une interface Streamlit legere par-dessus le gateway actuel.
- `option_2_k3s_scalability/`
  Propose une extension vers Kubernetes avec K3s comme cible legere, Streamlit comme front optionnel, et un monitoring cluster/applicatif plus complet.

La stack de reference reste celle du `docker-compose.yml` a la racine.
